# Meridian GNU/Linux
A derivative of Arch Linux that comes ready to use with Paru, drivers, and practicality in a TUI setup program.
Based on the `archiso` bootable environment, this distribution is intended for practicality and usage out of the box while being lightweight.

This distribution is currently not available and being developed in its beta phase. Logos, features, and changelogs are subject to change.

## Arch without the trouble
It's basically arch, archinstall, but comes with quality-of-life features such as paru (the AUR helper), NetworkManager, and other things. This is still a beta and will not likely see publication for some time (likely a week or few).
